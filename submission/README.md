- `run1_decisions.csv` — the blind batch under policy v5.0
- `run2_decisions.csv` — the same batch under the approved amendment

Use `npm run validate:csv -- submission/run1_decisions.csv` before pushing. Do not change code after the 10:00 build deadline; use the app's policy feature for the amendment.
